# Scope: Интернет-магазин

## В рамках проекта (In Scope)
- Каталог товаров, поиск, фильтры
- Корзина, оформление заказа
- Предзаказ / бронирование товара при временном отсутствии на складе
- Регистрация/авторизация покупателя
- Интеграция с одной платёжной системой (например, ЮKassa)
- Админка для управления товарами и заказами
- REST API для фронтенда

## Вне рамок проекта (Out of Scope)
- Мобильное приложение (только веб)
- Мультивалютность / мультиязычность
- Программа лояльности / бонусы
- Продажи от сторонних продавцов / маркетплейс-функционал

## Ограничения (Constraints)
- Технологические: Python, Django, React, PostgreSQL
- Временные: учебный проект без привязки к производственному дедлайну
- Бюджетные: бюджет отсутствует — pet-проект без привлечения платных сервисов/подрядчиков, только open-source и бесплатные тарифы инструментов

## Допущения (Assumptions)
- Оплата происходит через внешний платёжный шлюз, не собственная система
- Целевая аудитория имеет доступ к банковским картам/электронным кошелькам для онлайн-оплаты
- Поставщик (сам бренд) вручную актуализирует остатки товара на складе
