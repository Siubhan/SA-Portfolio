## 🎯 Цель

Продемонстрировать навыки:
- анализа бизнес-процессов;
- сбора и формализации требований;
- проектирования архитектуры;
- моделирования данных;
- проектирования API;
- документирования решений.

## 🧭 Как пользоваться репозиторием

Каждый проект оформлен по единой структуре и содержит одинаковый набор артефактов (см. раздел [Артефакты](#-артефакты)) — от Vision до Test Cases.

---

## 🧩 Артефакты

В каждом проекте представлены следующие документы:

| Документ | Описание |
|---|---|
| Vision | Видение продукта |
| Scope | Границы проекта |
| Business Requirements | Бизнес-требования |
| Functional Requirements | Функциональные требования |
| Non-functional Requirements | Нефункциональные требования |
| User Stories | Пользовательские истории |
| Use Cases | Сценарии использования |
| BPMN | Бизнес-процессы |
| UML | Диаграммы UML |
| ERD | Модель данных |
| SQL | Структура базы данных |
| OpenAPI | Спецификация REST API |
| Architecture | Архитектурные диаграммы |
| ADR | Архитектурные решения |
| Test Cases | Примеры тестовых сценариев |
